## gasPriceToken0Wad

On chain, token0 is native ETH in all three pools (`common/pools.py`: token0 = ETH, 18 decimals). There:
- the hook's numeraire is ETH;
- the reference price is ETH per token1;
- the gas term needs `gasPriceToken0Wad = 1e18`. With 0, `_kappa` prices gas at the reference (`ParticipationAwareHook.sol:420`), which is wrong by the factor ETH per token1.

| Place | Value | What it is |
|---|---|---|
| `BlockScopedHookTestBase._params` / `_finalParams` (gas suite, fuzz, V1 properties, scenarios, conformance hook) | 0 (unset) | Foundry tests on mock ERC-20 tokens, so neither token is ETH |
| `BlockScopeBoundary.t.sol:53` | 0, by design | checks the reference-priced path against `_kappa` |
| `BlockScopedHook.t.sol:325` | 2000e18 | checks the configured path |
| `BlockScopedHook.t.sol:360` | 0 | checks the reference-priced path |
| `common/fixedpoint.py` ScopedHookReference | default 0 | integer mirror |
| `block_scope_ffi.py`, `block_scope_v1_ffi.py` | the contract's value | ffi bridges |
| `tests/test_block_scope_reference.py:57` | 2000 × WAD | unit test |
| experiment configs (`experiments/configs/*.yml`, `config/*.json`) | not set | |
| deployment scripts | none exist | |

No stored result used a wrong value:
- **Python replays:** eC, Q2 and Q4 run ScopedHookReference with the pool's token1 (USDC/WBTC) as the hook's numeraire and ETH as the hook's token1 (`replay_rule`: `s0 = 10**dec1`). There, 0 makes the gas term use USDC per ETH, which is correct. This orientation is the reverse of the on-chain one, which only changes rounding.
- **eB/Q4/Q5 cross-block harnesses:** they price gas in USD directly (`gas × (basefee + tau) × 1e-18 × ETH/USD`).
- **Foundry gas table:** with 1e18 in `_finalParams`, measured in a scratch copy of ce983e8, every swap that opens a scope costs 4 gas more (an immutable read in place of the reference) and nothing else changes. All 39 gas tests pass. The deployment figures would therefore be 38,700 / 52,341 / 20,035 instead of 38,696 / 52,337 / 20,035.

A deployment on the real pools must set `gasPriceToken0Wad = 1e18` explicitly; the contract's NatSpec fallback assumes token1 is ETH.

## Daily whole-ppb eps (fce487b, run on ce983e8)

`eQ5_buffer_calibration.py --variants daily --tag daily`. At 00:00 UTC, eps is set to the rolling 7-day 95th percentile of the errors before that time, rounded up to whole ppb, and held for the day. It is compared with the per-candidate rolling p95 at the same query times. Relative difference = daily / rolling − 1:

| Pool | Query set | Median | p05 / p95 | Mean abs | Daily below rolling |
|---|---|---|---|---|---|
| ETH/USDC | observed swaps (98,087) | +0.05% | −4.5% / +4.2% | 1.7% | 44% |
| ETH/USDC | Experiment B opportunities (2,606) | 0.0% | −7.3% / +11.4% | 3.2% | 44% |
| ETH/WBTC (corr24h) | observed swaps (3,571) | 0.0% | −8.1% / +4.8% | 2.3% | 43% |
| ETH/WBTC (corr24h) | opportunities (442) | 0.0% | −25.7% / +23.2% | 7.1% | 39% |
| ETH/WBTC (raw) | observed swaps | 0.0% | −5.7% / +11.4% | 2.8% | 45% |
| ETH/WBTC (raw) | opportunities (515) | 0.0% | −27.9% / +27.6% | 7.3% | 45% |

Effect on the Q5 criteria:
- **ETH/USDC:** observed V1 transfer 38,722 -> 38,660 USD (−0.16%), tipped violations 95 -> 96, spillover 121 -> 125; Experiment B unsplit transfer −0.3%, survival at N = 5 83.4% -> 83.4%.
- **ETH/WBTC:** observed transfer +17% (corr24h) / +9% (raw), unsplit transfer +7% / +5%, tipped unchanged (3 / 4), survival at N = 5 82.8% / 83.0%. Its samples are small (3,571 swaps), so a few corrections move the transfer.

The daily admin update reproduces the per-candidate value closely for ETH/USDC, and the Q5 choice (p95) is unchanged.
